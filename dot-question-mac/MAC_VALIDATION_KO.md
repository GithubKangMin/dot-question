# Mac 검증 상태 · 2026-10-16

## 이전 버전에서 확인된 범위

빠른 질문 모드 변경 전 소스는 macOS 환경에서 XCTest 52개, 구조 검사 10개, release 빌드, Info.plist 및 ad-hoc 서명 검사를 통과했습니다. 격리된 빈 저장소로 앱 창과 메뉴 생성 및 정상 종료를 확인했습니다.

검사에는 합성 영어·한국어 OCR 이미지, 합성 PDF/TXT/MD 자료, 메뉴 아이콘 렌더링, 메모리 기반 응답 모의 전송을 사용했습니다. 실제 개인 자료나 API 키는 사용하지 않았습니다.

## 현재 소스

빠른 질문 모드와 RequestOrigin 테스트 3개가 추가되었습니다. 현재 소스의 Python 구조 검사는 통과했지만, 새로운 Swift 소스의 XCTest와 release 빌드는 macOS CI 실행을 기다리고 있습니다. 이전 52개 통과가 현재 소스의 전체 통과를 의미하지 않습니다.

## 별도 실제 기기 검증 범위

실제 화면 캡처·화면 기록 권한, 다중 모니터와 Retina 좌표, 전역 단축키·클립보드·메뉴 알림, 실제 로컬 모델 추론, 실제 API 연결, Caps Lock LED 쓰기·점멸·복원은 검증되지 않았습니다. Apple 공증 및 Developer ID 서명은 수행하지 않습니다. 합성 테스트는 실제 기기 검증을 대신하지 않습니다.
