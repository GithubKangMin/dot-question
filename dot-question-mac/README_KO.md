# dot question — macOS 현재 소스

내가 직접 선택한 화면 영역을 한국어·영어 OCR로 읽고, 질문을 수정한 뒤 내 Mac의 Ollama 또는 OpenAI API로 풀이를 요청하는 메뉴 막대 앱입니다. 독립적으로 작성한 앱 소스이며 다른 제품의 소스·바이너리를 포함하지 않습니다.

**빠른 모드 변경 전 기준으로 2026-10-16 macOS 환경에서 release 앱 빌드, XCTest 52개, 구조 검사 10개, 격리 실행·정상 종료를 확인했습니다.** 한국어·영어 합성 이미지의 Vision OCR, PDF/TXT/MD 가져오기·검색·출처, 메뉴 아이콘 렌더링 및 모의 응답을 검사했습니다. 실제 모델 호출, 화면 캡처·전역 단축키·클립보드 동작은 미검증입니다. 자세한 결과와 한계는 [MAC_VALIDATION_KO.md](MAC_VALIDATION_KO.md)에 있습니다. 임시 서명한 현재 Mac용 앱이며 Apple 공증 배포물이 아닙니다.

## 창을 열지 않는 로컬 빠른 모드 (새 변경 · 네이티브 재검증 대기)

- 처음에는 꺼져 있습니다. 질문 창에서 **로컬 빠른 모드**를 직접 켜면 설정이 저장됩니다.
- 로컬 Ollama와 화면 기록 권한을 준비하고, 다른 앱의 문제 위에 커서를 놓은 뒤 전역 단축키를 누릅니다. 설정 크기로 커서 주변을 캡처하고 OCR → 자료 검색 → 로컬 풀이를 자동 수행합니다. 완료 때 질문 창을 열지 않습니다.
- 빠른 모드는 API 공급자가 선택되어 있으면 전송 전에 중단합니다. API 자동 전송은 없으며 기존 수동 API 전송 확인 창을 유지합니다.
- 메뉴 답 표시는 처음부터 켜져 있고, 숫자/Wi-Fi형/배터리형 및 캐릭터·동작 줄이기 설정을 저장합니다. 답을 얻기 전에는 Q?, 실패·근거 없음·불확실한 선택 답에는 Q!와 메뉴 오류를 표시합니다. 오류 알림은 macOS 알림 설정에 따라 표시되지 않을 수 있어 메뉴에도 원인을 남깁니다.
- 빠른 모드를 저장한 뒤 다시 실행하면 창을 열지 않고 메뉴 막대에서 시작합니다. 메뉴의 **질문 창 열기**로 설정·상세 답·오류를 확인하고 **진행 중 작업 취소**로 취소할 수 있습니다.
- 일반 캡처 버튼은 기존 OCR 검토 → 직접 전송 흐름을 유지합니다. 앱의 메뉴 아이콘이며 실제 시스템 Wi-Fi/배터리 상태는 변경하지 않습니다.
- 이 변경은 Linux에서 구조 검사만 실행했습니다. 새 Swift 테스트는 추가했으나 macOS 빌드·테스트 및 실제 다른 앱 위 단축키 흐름은 GitHub Actions/macOS 재검증이 필요합니다. 아래 이전 Mac 검증 결과가 이 변경까지 검증했다는 뜻은 아닙니다.

## 준비

- API 모드는 앱 최소 타깃인 macOS 13 이상입니다. 로컬 Ollama 구성은 macOS 14 이상이 필요합니다. 현재 Ollama 배포판이 macOS 14 이상을 요구합니다.
- Swift 5.9 이상 및 XCTest가 포함된 Xcode. Command Line Tools만으로는 앱 컴파일이 가능해도 XCTest가 없을 수 있습니다. 터미널에서 `xcode-select --install`로 설치할 수 있습니다. 설치/약관 동의는 직접 진행하세요.
- Ollama: https://ollama.com/download/mac 공식 배포판을 직접 설치합니다. 이 프로젝트는 Ollama나 모델을 자동 설치하지 않습니다.
- 로컬 모델은 RAM과 디스크를 사용합니다. 기본 `qwen3:4b-instruct` 다운로드는 약 2.5GB이며 추론에는 추가 메모리가 필요합니다. 모델 다운로드에는 인터넷이 필요합니다.

## 두 가지 모드

기본값은 **로컬 · Ollama**입니다. 앱 위의 모드 선택에서 **API · OpenAI (유료)**로 바꿀 수 있습니다. 자동 전환하지 않습니다.

API 모드에서는 Ollama 설치가 필요 없습니다:

1. 본인의 OpenAI API 계정에서 사용 가능한 Chat Completions 모델명을 확인합니다. 기본 입력값은 `gpt-4.1-mini`이며 계정/모델 지원 여부에 따라 변경하세요.
2. API 키를 앱의 가려진 보안 입력칸에 직접 입력합니다. 키를 채팅으로 보내거나 코드에 넣지 마세요.
3. **OpenAI API로 전송 (유료)** → 데이터 전송/과금 확인 창에서 직접 승인합니다.

요청 목적지는 `https://api.openai.com/v1/chat/completions`로 고정되며 임의 API 호스트 설정은 없습니다. 승인한 질문과 검색된 자료 발췌는 OpenAI로 전송되지만 캡처 이미지 자체는 전송하지 않습니다. 키는 앱 실행 중 메모리에만 유지하며 UserDefaults, 파일, Keychain에 저장하지 않습니다. **키 지우기** 또는 앱 종료로 지울 수 있습니다. 모델명만 저장됩니다. API 모드에서는 인터넷이 필요하고 사용량에 따라 별도 요금이 발생할 수 있으며 ChatGPT 구독과 별도입니다. 앱은 가격이나 결제 한도를 계산하지 않습니다. 출력 상한을 설정해도 비용 상한을 보증하지 않습니다. 취소는 이미 서버에서 처리한 요청에 대한 환불을 뜻하지 않습니다.

API 요청은 `store: false`를 포함하지만 이것이 모든 제공자 로그·보관 정책을 없애는 것은 아닙니다. OpenAI API 데이터 정책을 확인하세요: https://platform.openai.com/docs/guides/your-data

실제 API 키나 유료 API 호출을 사용한 개발 테스트는 하지 않았습니다.

## 로컬 모델 설정

Ollama가 클라우드 모델 요청을 중계할 수 있으므로 **Ollama 클라우드 기능을 비활성화**하세요. 터미널 서버를 사용하는 예:

```sh
# 실행 중인 Ollama 앱/서버를 먼저 종료합니다.
OLLAMA_NO_CLOUD=1 ollama serve
```

그 터미널을 유지하고 새 터미널에서 원하는 모델을 직접 내려받습니다:

```sh
ollama pull qwen3:4b-instruct
ollama list
```

GUI Ollama를 계속 사용하려면 공식 FAQ의 `disable_ollama_cloud: true` 설정을 적용하고 재시작하세요: https://docs.ollama.com/faq

로컬 모드의 앱은 루프백 HTTP 주소만 허용하고 `localhost`를 `127.0.0.1`로 고정합니다. 시스템 프록시를 사용하지 않고 HTTP 리디렉션도 차단합니다. 매 전송 전 `/api/tags`에서 설치 모델을 확인하고 `remote_model` / `remote_host` 필드가 있는 모델 및 이름에 `cloud`가 포함된 모델을 거부합니다. 다만 다른 로컬 서버나 향후 서버 구현이 데이터를 어떻게 처리하는지는 앱이 보증할 수 없으므로, 신뢰하는 로컬 Ollama와 클라우드 비활성화 설정을 함께 사용하세요.

## 빌드 및 실행

압축을 푼 프로젝트 폴더에서 터미널로 실행합니다:

```sh
chmod +x build.command
./build.command
```

실행 권한을 준 뒤 Finder에서 `build.command`를 더블클릭해도 됩니다. 스크립트는 XCTest가 없으면 이미 설치된 `/Applications/Xcode.app`을 명령 실행 범위에서만 선택합니다. 시스템 개발 도구 선택이나 보안 설정은 변경하지 않습니다. 이어서 Swift 단위 테스트 → release 빌드 → `dist/dot question.app` 생성 → 임시(ad-hoc) 서명을 수행합니다. 현재 Mac의 아키텍처만 빌드합니다. Apple 공증 배포 앱이 아니므로 다른 Mac에 복사하는 정식 배포 용도로는 적합하지 않습니다. 보안 경고를 무작정 우회하지 마세요.

생성된 앱을 Finder로 엽니다. 메뉴 막대의 `Q?`가 남아 있으며 창을 닫아도 앱이 종료되지 않습니다. 종료는 Q? → 종료입니다. 앱을 일정한 경로에 두면 화면 기록 권한 관리가 편합니다.

## 사용

1. `Control + Option + Command + R` 또는 메뉴의 **영역 캡처**를 선택합니다.
2. 첫 실행에서 macOS가 화면 기록 권한을 요청하면 직접 허용합니다. 시스템 설정 → 개인정보 보호 및 보안 → 화면 기록(버전에 따라 화면 및 시스템 오디오 기록)에서 앱을 확인하고 앱을 종료·재실행하세요.
3. 원하는 문제 영역을 드래그합니다. Esc로 취소합니다.
4. 추출된 질문을 수정합니다. 캡처만으로는 AI에 전송되지 않습니다.
5. 로컬 모드에서 **로컬 AI로 전송**, API 모드에서 **OpenAI API로 전송 (유료)**을 클릭합니다. 답변/풀이를 확인하거나 **답변 복사**를 누릅니다.
6. **취소**는 진행 중 요청을 취소하고 늦은 응답을 무시합니다. OCR 취소는 해당 작업이 마무리될 때까지 잠시 기다립니다.

질문을 직접 붙여넣어도 됩니다. 모델·자료·캡처·표시 옵션은 창 위의 ‘설정 펼치기’에서 변경합니다. 기본 창에서는 설정을 접어 질문과 풀이를 먼저 보여줍니다. 서버 주소, 각 모드의 모델명과 단축키 선택이 설정에 저장되며 질문과 답변은 앱에서 기록 파일로 저장하지 않습니다. 임시 캡처는 OCR 완료·실패·취소·정상 종료 시 삭제됩니다. 강제 종료/전원 손실 시 임시 폴더에 파일이 남을 수 있습니다. 클립보드 복사는 복사 버튼 또는 사용자가 켠 자동 복사 옵션으로 수행되며 macOS 클립보드 동기화가 켜져 있으면 Apple 기기로 동기화될 수 있습니다.

### 자료 사용

‘자료 가져오기’에서 PDF/TXT/MD를 선택합니다. 추출·색인은 백그라운드에서 실행되고 원본 파일을 수정하지 않습니다. 파일당 20MiB, PDF 500쪽, 추출 텍스트 200만 자, 전체 저장 텍스트 1,000만 자, 문서 100개 한도입니다. 초과하면 명시적으로 거부하며 조용히 잘라 저장하지 않습니다. 텍스트 파일은 UTF-8 또는 BOM 있는 UTF-16을 지원합니다. 스캔 PDF는 먼저 별도 OCR이 필요합니다. 일부 페이지만 이미지인 PDF는 해당 페이지 내용이 색인되지 않을 수 있습니다.

추출 텍스트는 이 Mac의 `~/Library/Application Support/DotQuestion/documents.json`에 원자적으로 저장합니다. 암호화 저장소는 아니며 OS 백업 정책의 영향을 받을 수 있습니다. 선택 자료 삭제는 가져온 텍스트만 제거하고 원본은 유지합니다. 손상된 저장소는 덮어쓰지 않고 오류를 표시합니다. 원본 문서 경로나 API 키는 저장하지 않습니다.

‘자료 근거 모드’를 켜면 관련 검색 결과가 없을 때 전송하지 않습니다. API는 최대 6개/7200자, 로컬은 문맥 보호를 위해 최대 3개/2400자의 발췌를 선택합니다. 검색은 로컬 키워드 순위 기반이며 의미 이해/전체 문서 정독을 보장하지 않습니다. API 확인창에서 질문과 발췌 전문을 검토한 뒤 매번 전송을 승인합니다. 가져오기만으로 외부 업로드하지 않습니다.

응답 JSON의 실제 보기 label, 풀이, 출처 ID를 검증합니다. 허용 목록 밖 출처/보기, 누락된 풀이 등은 미검증 원문으로만 표시하며 자동 복사·선택 신호를 내보내지 않습니다. 출처 ID 검증은 내용의 사실성 검증과 다릅니다. 불확실성 표시가 있는 답변은 자동 복사와 메뉴 번호·캐릭터 신호를 내보내지 않습니다.

### Wi-Fi형 / 배터리형 메뉴 답

‘메뉴 막대에 선택 답 표시’를 켜고 ‘메뉴 답 표시 모양’에서 숫자 / Wi-Fi형 막대 / 배터리형을 선택합니다. 앱의 Q 표시가 있는 별도 메뉴 항목입니다. macOS 시스템 Wi-Fi·배터리 항목을 대체하거나 실제 네트워크·배터리 사용량을 바꾸지 않습니다. 툴팁에도 답 표시이며 실제 상태가 아님을 표시합니다.

- Wi-Fi형: 보기 순서 1–5를 채워진 막대 1–5칸으로 표시합니다. 6–10번은 혼동을 피하려고 Q 6 … Q 10 숫자로 표시합니다.
- 배터리형: 보기 순서 1–10을 10%, 20%, …, 100%로 표시합니다. 예: B/②/2번 → 20%. 실제 배터리 잔량이 아닙니다.
- 선택지의 문자 자체가 아니라 보기 순서로 매핑합니다. AI의 불확실 응답, 선택 없음, 응답 검증 실패, 새 전송 및 내용 지우기는 아이콘을 지우고 중립 Q?로 돌아갑니다.
- 고양이를 함께 켜면 먼저 해당 횟수만큼 움직이고 선택한 메뉴 답 모양으로 돌아옵니다. 출력 설정 변경은 진행 중 고양이 움직임을 중단하고 즉시 반영됩니다. Enter 준비 동안은 준비 문구가 우선합니다.
- 출력 설정은 실행할 때마다 기본 꺼짐이며 모양은 숫자로 시작합니다. 화면 공유에 보일 수 있습니다.

### 캡처와 출력 설정

커서 중심 캡처를 켜고 너비·높이를 입력하면 커서가 있는 화면 안의 사각형을 캡처합니다. 선택을 끄면 직접 드래그합니다. Enter 준비를 켜면 먼저 설정된 보조키 단축키를 누르고 10초 이내 문제 위에 커서를 놓아 Return을 누릅니다. 이 기간의 Return은 다른 앱에 입력되지 않을 수 있습니다. Esc로 해제할 수 있고 항상 켜진 전역 Enter 감시는 하지 않습니다. 등록 실패 시 준비 모드를 끄고 보조키 단축키로 직접 캡처하세요.

자동 복사·캐릭터는 기본 꺼짐이며 메뉴 답 표시는 기본 켜짐입니다. 각 설정은 개별적으로 바꿀 수 있습니다. 메뉴 답은 숫자 / Wi-Fi형 막대 / 배터리형 중 선택하고, 캐릭터는 끄기 / 고양이 꼬리 흔들기 / 피카츄 전기 펄스 중 선택합니다. 캐릭터는 검증된 객관식 보기 순서 1–10만큼 초당 1회 움직입니다. 메뉴 답도 켜면 캐릭터 신호 후 선택한 숫자/막대/배터리 모양으로 돌아갑니다. 메뉴 답을 끄고 캐릭터만 켜면 정지한 캐릭터와 번호가 남습니다. 움직임 줄이기 옵션 또는 macOS 동작 줄이기를 켜면 애니메이션 없이 최종 정적 표시만 나옵니다. 고양이와 피카츄는 코드로 직접 그린 AppKit 벡터 그림이며 외부 이미지 다운로드나 공식/라이선스 캐릭터 에셋이 아닙니다. 새 질문 입력·새 캡처·전송·오류·취소·창 닫기·종료에서는 신호를 초기화하고, 출력 모드 변경에서는 진행 중 애니메이션을 중지한 뒤 현재 설정으로 표시합니다.

캡처 후에는 질문을 확인하고 전송 버튼을 누릅니다. 자동 외부 제출은 없습니다. API 모델은 JSON mode를 지원해야 합니다. 로컬은 16,384 토큰 문맥을 요청하고 질문+시스템 프롬프트 UTF-8 총 14KB를 넘으면 문맥 잘림을 피하려고 거부합니다. 큰 질문은 나눠 주세요. 전체 프롬프트도 3만 자 한도가 있습니다. 요청은 비스트리밍이며 최대 자원 대기 180초입니다.

앱 창·메뉴 막대·고양이는 화면 공유에서 보일 수 있습니다. 숨김·탐지 회피를 보장하지 않습니다. AI 답변은 틀릴 수 있으며 해당 서비스/시험 규칙을 지켜 사용하세요.

## 문제 해결

- `swift: command not found`: Command Line Tools 설치 완료 후 새 터미널에서 재실행.
- Swift 도구 버전 오류: Swift 5.9 이상이 필요합니다. `xcrun swift --version` 확인.
- 연결 실패: `ollama serve` 실행, 포트 충돌, 주소 `http://127.0.0.1:11434` 확인.
- 모델 없음: `ollama list`의 이름과 앱 모델명이 일치해야 합니다. 모델은 직접 설치하세요.
- 빈 OCR: 영역을 확대하고 높은 대비의 텍스트만 선택하세요. 직접 입력도 가능합니다.
- 캡처 권한 문제: 실제 앱을 Finder에서 실행해 권한을 허용하고 재실행. `swift run`이나 터미널 직접 실행은 macOS가 권한 주체를 다르게 표시할 수 있습니다.
- 단축키 무반응: Q? 메뉴 캡처로 확인 후 다른 앱의 동일 단축키를 확인하세요.

## 검증

Linux에서 실행 가능한 정적 구조 검사:

```sh
python3 scripts/check_source.py
bash -n build.command
```

이 검사는 Swift 컴파일이나 기능 테스트가 아닙니다. macOS에서는 `./build.command`로 XCTest와 release 빌드를 함께 실행합니다. `swift test`만 따로 실행할 때는 XCTest를 제공하는 Xcode 도구를 선택하세요. 다음 항목은 별도 수동 확인 범위입니다: 다음 항목을 수동 확인하세요:

- 한글/영문 캡처, 직접 입력, OCR 수정 후 전송, 답변 복사
- 최초 권한 거절 후 허용·재실행, Esc 캡처 취소, 단축키 충돌
- 전송 중 취소, 캡처/OCR 중 취소, 반복 클릭, 창 닫기 및 다시 열기
- Ollama 미실행, 모델 미설치, cloud 모델 거절, 로컬 모드 원격 URL/리디렉션 거절
- API 키 빈칸, API 확인창 취소, 키 지우기, 401/403/404/429 오류, 모드 전환 중지(요청 중 비활성화), 종료 후 키 미보관
- 서버 지연/시간 초과, 앱 종료, 임시 이미지 삭제
- PDF/TXT/MD 가져오기·재실행 후 유지·선택 삭제·손상 저장소·크기 한도·빈/스캔 PDF
- 자료 무검색 결과 시 전송 거절, 출처 파일/페이지 대조, 허위 source ID/선택지/잘못된 JSON 거절
- 커서 캡처 다중 화면/Retina/화면 경계, 세 가지 단축키 충돌
- Enter 준비 후 다른 앱에서 Return, Esc, 10초 시간초과, 준비 중 모달/앱 종료
- 작은 화면에서 전체 창 스크롤 및 API 발췌 전문 스크롤
- 자동 복사 기본 꺼짐, 불확실/검증 실패 응답의 신호 억제, 고양이 반복 횟수
- Wi-Fi형 1–5칸 및 6–10 숫자 대체, 배터리형 10–100%, A/①/ㄱ 순서 매핑, 불확실/오류/새 전송/지우기의 Q? 복원
- 숫자 ↔ Wi-Fi형 ↔ 배터리형 및 캐릭터 끄기 ↔ 고양이 ↔ 피카츄 전환, 보기 순서 1/5/10의 꼬리/전기 신호 횟수, 완료 후 선택 메뉴 답 모양 복원
- 앱 움직임 줄이기 및 macOS 동작 줄이기, 애니메이션 중 질문 편집/새 캡처/취소/창 닫기/종료/출력 모드 변경, Enter 준비/취소, 밝은/어두운 메뉴 막대 및 Retina에서 캐릭터·Q 표시·툴팁 확인

## 기존 자료를 사용하지 않는 실행 확인

```sh
"dist/dot question.app/Contents/MacOS/DotQuestion" --smoke-test
```

임시 빈 자료 저장소와 별도 설정으로 창·Q? 메뉴를 열고 자동 종료합니다. 기존 자료를 읽지 않고 전역 단축키를 등록하지 않습니다. 모델 요청·캡처·클립보드 쓰기도 하지 않습니다. 접근 권한을 자동 승인하지 않으며, `--smoke-image <작업 폴더 내 PNG 경로>`는 앱 자체 빈 창의 렌더링만 저장합니다. 일반 실행은 이 옵션 없이 앱을 엽니다.
