# dot question · Windows 소스

선택한 화면의 한국어/영어를 로컬 OCR로 읽고, 수정한 질문을 내 PC의 Ollama 또는 OpenAI API로 보내는 Windows용 데스크톱 앱입니다. 자료 PDF/TXT/MD 검색, 객관식 보기 검증, 출처 표시와 선택적 트레이 신호를 포함합니다.

**제공물은 소스 ZIP입니다. Windows에서 실행 검증한 EXE/설치 프로그램이 아닙니다.** Linux 환경에서 작성하고 코어 단위 테스트/파이썬 문법 검사와 Linux 오프스크린 Qt 창 생성 검사를 수행했습니다. 실제 Windows 화면 캡처, DPI, OCR, 전역 단축키, 트레이, 유료 API 응답은 아래 수동 검증이 필요합니다. Mac 바이너리를 Windows 실행 파일로 바꾼 것이 아니라 Python/PySide6로 작성한 별도 구현입니다.

## 빠른 시작 (사용자가 직접)

권장 환경: Windows 11 x64, Python 3.11 이상 x64. Windows ARM/32bit는 지원 검증하지 않았습니다.

1. https://www.python.org/downloads/windows/ 에서 Python을 설치합니다. Python Launcher(`py`)가 필요합니다. 관리자 권한이 필요 없는 사용자 설치를 선택할 수 있습니다.
2. ZIP을 쓰기 가능한 개인 폴더에 풉니다.
3. `setup.cmd`를 실행합니다. 프로젝트 안 `.venv`를 만들고 공식 PyPI에서 PySide6/pypdf를 설치하고 단위 테스트를 실행합니다. 다운로드에는 인터넷이 필요합니다. 시스템 Python 패키지나 실행 정책은 변경하지 않습니다.
4. `run.cmd`를 실행합니다. OCR이나 로컬 AI를 아직 설치하지 않아도 질문 붙여넣기와 API 모드를 사용할 수 있습니다.

프로젝트에는 관리자 권한 요청, PowerShell 실행 정책 변경, 자동 로그인 실행/서비스 등록, 키보드 후킹, 시스템 Wi-Fi/배터리 변경 기능이 없습니다. 설치/다운로드/모델 실행은 사용자가 직접 선택합니다.

### 선택: Windows EXE 만들기

Windows PC에서 `build.cmd`를 실행하면 PyInstaller를 프로젝트 가상환경에 설치하고 테스트 후 `dist\DotQuestion\DotQuestion.exe`를 만듭니다. **폴더 전체를 함께 보관/전달**해야 합니다. Tesseract와 Ollama/모델은 포함하지 않습니다. PyInstaller는 크로스 컴파일러가 아니므로 이 Linux 환경에서 Windows EXE를 검증/제공하지 않았습니다. 코드 서명이나 Microsoft 인증 배포가 아니며 보안 경고를 무작정 우회하지 마세요. 조직 PC는 조직 정책을 따르세요.

## 오프라인 OCR 설정 (선택)

Tesseract 엔진과 `kor`/`eng` 언어 자료를 사용자가 직접 설치합니다. 공식 프로젝트 설치 안내: https://tesseract-ocr.github.io/tessdoc/Installation.html

Windows 배포 링크는 공식 문서가 안내하는 제3자 빌드일 수 있습니다. 출처와 서명을 직접 확인하세요. 이 앱이 설치 파일을 다운로드하거나 실행하지 않습니다. PATH의 `tesseract.exe` 또는 일반 설치 경로를 검색합니다. 앱을 시작한 명령창에서 `TESSERACT_CMD` 환경변수로 실행 파일 절대 경로를 지정할 수도 있습니다. 영어 전용으로 사용할 때는 앱 실행 전 `OCR_LANG=eng` 환경변수를 설정할 수 있습니다. 누락된 엔진/언어 자료는 오류로 알려주며 질문 직접 입력은 계속 가능합니다.

이미지는 메모리 PNG로 변환하고 Tesseract 표준입력으로 전달합니다. 앱은 캡처 이미지 파일을 저장하지 않습니다. OCR은 캡처 영역의 한글/영문 텍스트용이며 복잡한 수식·표·그림의 의미를 정확히 읽지 못할 수 있습니다. OS 메모리/스왑/스크린샷 도구의 별도 기록까지 통제하지 않습니다.

## AI 설정

### 로컬 Ollama (기본)

공식 다운로드: https://ollama.com/download/windows

Ollama와 모델은 앱에 포함하지 않습니다. 모델은 디스크와 RAM을 사용하며 다운로드에는 인터넷이 필요합니다. 예시 기본 모델은 `qwen3:4b-instruct`입니다. `ollama list`에서 실제 설치 이름을 확인하세요.

Ollama의 클라우드 기능을 비활성화하는 공식 방법: https://docs.ollama.com/faq

Ollama 앱/서버를 먼저 종료하고 별도 명령 프롬프트에서 다음을 사용하면 그 명령창의 서버 프로세스에만 적용됩니다.

```
set OLLAMA_NO_CLOUD=1
ollama serve
```

다른 명령창에서 `ollama pull qwen3:4b-instruct`를 직접 실행하여 모델을 준비합니다. GUI 서버와 중복 실행하여 포트가 충돌하지 않도록 하세요.

앱은 루프백 HTTP 주소만 허용하고 localhost를 127.0.0.1로 고정합니다. 시스템 프록시와 HTTP 리디렉션을 사용하지 않으며 전송 전 설치 모델 목록을 확인해 cloud/remote 표시 모델을 거부합니다. 다른 로컬 서버의 실제 동작을 증명하는 보안 경계는 아니므로 신뢰하는 Ollama와 클라우드 비활성화를 함께 사용하세요.

### OpenAI API (유료)

Ollama 없이 이용 가능합니다. 자신의 API 키를 앱의 가려진 입력칸에 직접 입력하세요. 키는 세션 메모리에만 유지하며 저장하지 않습니다. `키 지우기` 또는 앱 종료로 입력값을 지웁니다. 진행 중 요청이 보유한 키 사본은 그 작업 종료 때까지 메모리에 남을 수 있습니다. Python 문자열의 메모리 완전 삭제는 보장하지 않습니다.

요청 목적지는 `https://api.openai.com/v1/chat/completions`로 고정됩니다. 매 요청마다 모델명, 질문과 검색 발췌 전문을 보여주며 전송/과금을 승인해야 진행합니다. 캡처 이미지는 보내지 않습니다. 기본 모델명 `gpt-4.1-mini`는 예시이며 계정에서 지원되는 JSON mode Chat Completions 모델을 선택하세요. ChatGPT 구독과 API 요금은 별도입니다. 앱은 비용을 계산하거나 지출 상한을 보증하지 않습니다.

`store:false` 요청 옵션은 모든 서버 로그/보관을 없애는 의미가 아닙니다. 데이터 정책: https://platform.openai.com/docs/guides/your-data · 요금: https://openai.com/api/pricing/

취소는 결과 표시를 중단하며 이미 보내진 요청이나 그 요금을 되돌리지 않습니다. API 키나 실제 유료 API를 사용한 테스트는 수행하지 않았습니다.

## 사용 순서

1. 캡처 버튼 또는 Ctrl+Alt+Shift+R을 누르고 영역을 드래그합니다. Esc로 취소합니다.
2. 커서 중심 옵션을 켜면 커서가 있는 화면 내 사각형(기본 900×600 논리 픽셀)을 캡처합니다. 경계에서 잘립니다.
3. 기본 수동 모드에서는 OCR 결과를 검토/수정합니다. 캡처만으로 AI에 전송하지 않습니다.
4. 필요하면 PDF/TXT/MD를 가져오고 자료 근거 모드를 켭니다. 가져오기 자체는 외부 업로드가 아닙니다.
5. 전송 버튼을 눌러 답변을 받습니다. API는 매번 전송/과금 확인창이 열립니다.
6. 답변/출처를 검토하고 필요할 때 답변 복사를 누릅니다.

### 다른 앱 위에서 로컬 빠른 모드

1. 로컬 Ollama와 모델/OCR를 먼저 준비하고 앱에서 로컬 모드를 선택합니다.
2. `로컬 빠른 모드` 체크박스를 켭니다. 기본값은 꺼짐이며, 켜면 단축키 캡처 텍스트를 로컬 Ollama로 자동 전송하는 데 동의하는 설정입니다. 켜는 순간 트레이 답 표시도 켜집니다.
3. 트레이 표시 방식(number/wifi/battery)과 캐릭터(off/cat/pikachu)를 고르고 창을 닫아 숨깁니다.
4. 문제를 표시한 다른 앱에 커서를 놓고 전역 단축키를 누릅니다. 빠른 모드에서는 커서 중심 옵션과 관계없이 지정한 너비/높이의 커서 중심 캡처 → 오프라인 OCR → 로컬 Ollama → 트레이 답 표시가 이어집니다. 자체 창을 다시 열거나 다른 앱의 포커스를 가져오지 않습니다.
5. 오류/빈 OCR/모델 실패는 트레이 알림과 지속되는 Q! 아이콘·툴팁·메뉴 상태에 표시하며 창이나 대화상자를 열지 않습니다. 불확실하거나 선택 번호가 없는 답도 같은 방식으로 알리고 답변 전문은 창에서 검토할 수 있게 남겨 둡니다. API 모드에서 빠른 캡처를 시도하면 캡처/전송 전에 거부합니다. 자동 API 전송이나 API 동의창으로의 자동 전환은 없습니다. API를 쓰려면 직접 전송하여 기존 매 요청 확인을 거칩니다.

캡처 버튼과 트레이의 캡처 메뉴는 빠른 모드가 켜져 있어도 수동 검토 흐름을 사용합니다. 빠른 자동 흐름은 전역 단축키에만 적용됩니다. 빠른 모드를 저장한 뒤 다시 실행하면 시스템 트레이가 있는 환경에서 창을 열지 않습니다. 트레이가 없으면 설정 창을 표시합니다.

빠른 모드, 답 표시, 표시 스타일, 캐릭터, 움직임 줄이기는 `%LOCALAPPDATA%\DotQuestion\preferences.ini`에 저장됩니다. 답 표시는 기본 켜짐이고 유효한 답을 받기 전에는 중립 Q?입니다. 이전 답/애니메이션은 새 캡처·전송·취소·오류 때 초기화됩니다. 캐릭터를 선택하면 정지 상태에서도 캐릭터와 번호가 함께 보입니다. 빠른 모드를 다시 끄면 기존 수동 검토 흐름으로 돌아갑니다.

질문과 답변, 키, 모델/주소, 자동 복사, 캡처 크기와 단축키 설정은 세션 전용으로 저장하지 않습니다. 자료 텍스트는 `%LOCALAPPDATA%\DotQuestion\documents.json`에 저장합니다. 이는 암호화 저장소가 아니며 OS 백업이나 계정 동기화 정책의 영향을 받을 수 있습니다. 원본 파일과 API 키는 저장하지 않습니다. 선택 자료 삭제는 앱의 추출 텍스트만 제거하고 원본은 유지합니다. 손상된 자료 저장소는 자동 덮어쓰지 않습니다. 복구/삭제 전 원본을 보관하세요.

자료 검색은 로컬 키워드 순위 방식이며 벡터 임베딩이나 전체 자료 정독이 아닙니다. PDF의 내장 텍스트만 추출하며 스캔 PDF는 별도 OCR이 필요합니다. 이미지 페이지만 있는 문서, 표, 수식은 누락될 수 있습니다. UTF-8 또는 BOM 있는 UTF-16 텍스트를 지원합니다. 파일당 20MiB, PDF 500쪽, 문서당 200만 자, 전체 1,000만 자, 문서 100개 한도이며 초과하면 오류로 알려줍니다. 검색 발췌는 API 최대 6개/7,200자, 로컬 최대 3개/2,400자입니다. 전체 프롬프트는 30,000자, 로컬은 추가로 UTF-8 14KB 한도가 적용됩니다.

자료 근거 모드에서 관련 검색 결과가 없으면 전송하지 않습니다. 출처 ID와 보기의 유효성 검사는 실제 사실성/출처와 결론의 일치 검증이 아닙니다. 객관식은 줄 단위 `①`, `A.`, `(A)`, `1.`, `(1)`, `ㄱ.` 등의 보기를 인식합니다. 복잡한 보기 배치는 직접 줄바꿈을 수정하세요.

## 트레이, 단축키, 취소

- 창 닫기는 트레이가 있는 환경에서 창을 숨깁니다. 트레이 메뉴의 종료로 앱을 끝냅니다. 창 닫기/취소/종료/새 질문은 기존 선택 신호를 초기화합니다.
- 단축키는 Ctrl+Alt+Shift와 R/Space/Enter 중 선택합니다. 충돌하면 상태 메시지로 알려주며 캡처 버튼은 계속 쓸 수 있습니다.
- Enter 준비 옵션을 켜면 먼저 위 보조키 단축키를 누르고 10초 안에 Enter로 캡처합니다. 이 기간의 Enter/Esc는 다른 앱에 입력되지 않을 수 있습니다. 실행/취소/시간초과/종료 때 임시 등록을 해제합니다. 상시 Enter 감시나 키보드 후킹은 하지 않습니다.
- 검증된 객관식 답과 불확실성 없는 응답만 트레이 신호로 표시합니다. 번호 1–10을 지원하고 Wi-Fi형 6–10은 숫자로 표시합니다. 배터리형은 번호×10%입니다. 번호는 보기 라벨이 아닌 등장 순서입니다.
- Wi-Fi형/배터리형은 Q 표시가 있는 앱 자체 아이콘입니다. 실제 Windows 네트워크/전원 수치를 변경하거나 대체하지 않습니다.
- 캐릭터는 직접 그린 작은 고양이/피카츄풍 벡터이며 공식 캐릭터 자산이 아닙니다. 선택 순서만큼 약 1초 주기로 움직입니다. 움직임 줄이기는 정적 표시입니다. 자동 복사/캐릭터는 기본 꺼짐이며, 선택 표시는 기본 켜짐입니다.
- 자동 복사를 켜면 검증된 답변이 기존 클립보드를 덮어씁니다. Windows 클립보드 기록/동기화가 켜져 있으면 다른 기기로 전달될 수 있습니다.
- 앱, 캡처 선택창, 트레이 표시는 화면 공유에 보일 수 있습니다. 숨김이나 탐지 회피를 보장하지 않습니다. 시험/업무/서비스 이용 규칙에 맞게 사용하세요.
- Windows Caps Lock LED, 키보드 백라이트, 디스플레이 하드웨어 밝기 제어는 포함하지 않습니다. 키 입력/화면 깜박임으로 대체하지 않습니다.
- 작업 취소는 늦은 결과를 무시합니다. 진행 중 HTTP/OCR 작업을 강제 종료하지 않으므로 끝날 때까지 새 작업이 비활성화될 수 있습니다. 가져오기 중 취소해도 이미 저장된 자료는 남을 수 있으며 목록에서 삭제할 수 있습니다.
