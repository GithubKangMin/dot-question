# 검증 기록 · 2026-10-16

## 실행한 검사

환경: Linux, Python 3.12.14, PySide6 6.12.0, pypdf 6.20.1.

- `python -m py_compile app.py core.py win_capture.py icons.py tests/*.py` 통과
- 코어 단위 테스트 58개: 시스템 Python과 가상환경 양쪽 통과
- 전체 단위/스모크 테스트 95개: 코어 58 + 플랫폼 합성 15 + UI 22, 모두 통과
- 오프스크린 Qt 창을 실제 생성하고 한글 UI 렌더링 확인
- 트레이 1–10, 숫자/Wi-Fi/배터리, 캐릭터 렌더링 확인
- 합성 이미지로 음수 좌표/혼합 DPI 화면 조합 검사
- 가짜 Windows API로 단축키 등록/충돌 롤백/Enter·Esc·시간초과·종료 해제 검사
- API 승인 취소 시 클라이언트 생성/전송이 없는 흐름 확인
- 빠른 모드 기본 꺼짐/트레이 답 기본 켜짐 및 재시작 시 빠른 모드·스타일·캐릭터·움직임 설정 유지 검사
- 커서 캡처 → OCR → Ollama → 트레이의 전체 빠른 흐름을 모의 실행하고 창 활성화/경고 대화상자가 없는지 검사
- API 선택 시 캡처 전 차단 및 요청 시작 시 재차 차단, API 클라이언트/동의창이 호출되지 않는지 검사
- 빈 OCR, 캡처 실패, 모델 실패는 트레이 알림만 표시하고 오래된 답을 지우는지 검사
- OCR 도중 취소하면 로컬 모델을 호출하지 않으며, 취소가 답/애니메이션을 초기화하는지 검사
- 수동 OCR과 캡처 버튼은 빠른 모드가 켜져도 전송 버튼을 기다리고, 움직임 줄이기에서도 선택한 캐릭터가 정적으로 표시되는지 검사
- 불확실/선택 번호 없음은 Q!·툴팁·메뉴 오류와 알림을 남기고 답변 전문은 보존하며, 출력 설정 변경에도 오류가 유지되는지 검사
- 저장된 빠른 모드 시작 시 트레이가 있으면 창 숨김, 없으면 창 표시 및 빠른 모드를 켤 때 답 표시도 켜지는지 검사
- 비동기 요청과 취소 후 늦은 결과 무시, PDF 페이지 출처 표시 확인
- Linux의 설치된 Tesseract로 합성 영문 이미지의 메모리 PNG 입력 → 텍스트 출력 확인: “The answer is option two.”

모든 자동 테스트는 실제 외부 모델/API 호출 없이 수행했습니다. HTTP는 모의 전송으로 검사하며 코어 테스트는 실제 소켓 연결을 차단합니다. 테스트에는 실제 API 키나 개인 문서를 사용하지 않았습니다.

## 수행하지 않은 검사

Windows 실행, Windows PyInstaller EXE 빌드/코드서명, 실제 Windows 전역 단축키 전달/다른 앱 포커스 유지/트레이 알림/다중 모니터/DPI/한국어 OCR, 실제 Ollama 모델 응답, 실제 유료 OpenAI API 호출은 검증하지 않았습니다. 합성/모의 검사는 이 확인을 대신하지 않습니다.

오프스크린 환경에는 실제 시스템 트레이가 없으므로 Qt 시스템 트레이 경고가 나올 수 있습니다. 테스트 통과는 해당 기능의 Windows 기기 동작을 보증하지 않습니다.
